# Portfolio — Axel Boursin

Site statique bilingue, hébergé sur GitHub Pages.

- `index.html` : version française (https://axelboursin.github.io/)
- `en/index.html` : version anglaise (https://axelboursin.github.io/en/)
- `assets/site.css` et `assets/site.js` : styles (dont la mise en page PDF), filtres de projets et bouton « Exporter en PDF », partagés par les deux langues

## Mettre à jour
Modifier le contenu dans **les deux** fichiers HTML pour garder les versions alignées, puis :

```bash
git add -A && git commit -m "Mise à jour du portfolio" && git push
```

Le site est republié automatiquement en ~1 minute.
